# Gestor de Tareas

Aplicacion web de lista de tareas construida unicamente con HTML, CSS y JavaScript puro. No necesita backend, base de datos ni proceso de compilacion.

## Funciones

- Agregar tareas con un formulario.
- Marcar tareas como completadas.
- Eliminar tareas individualmente.
- Filtrar entre Todas, Pendientes y Completadas.
- Limpiar todas las tareas completadas.
- Guardar automaticamente los datos en `localStorage`.
- Indicador visual del progreso y cantidad de tareas.
- Diseno responsive para escritorio y dispositivos moviles.

## Uso

Abre `index.html` directamente en un navegador moderno. Las tareas se guardan en el almacenamiento local del navegador y permanecen disponibles en el mismo dispositivo y navegador.

## Estructura

- `index.html`: estructura y contenido de la aplicacion.
- `style.css`: estilos responsive, estados y animaciones.
- `script.js`: creacion, renderizado, filtros y persistencia de tareas.
